研究台 · 新手手册

十分钟上手，
从放进论文到读懂它

研究台是装在你自己电脑上的论文阅读助手。不用懂代码，按下面的步骤做一次设置，以后双击就能用。

STEP 1把 PDF 放进文库拖进窗口，标题、作者、出处自动填好
STEP 2读原文，问 AI划词翻译、解释、提问、拆解
STEP 3留下自己的东西高亮、笔记、想法、计划
完全免费论文和笔记只存在你的电脑上Mac 和 Windows 都能用
01

第一次打开

只需要做一次。以后每次使用，从第 3 步开始就行。

  1. 下载并解压

    在项目的 GitHub 页面点绿色的 Code → Download ZIP。下载后先完整解压，解压出来的文件夹叫「仓库名-main」，例如 research-desk-main。不要在压缩包里直接双击。

  2. 准备 Python（只需一次）
    MAC通常不用装。第一次启动时如果弹窗让你安装「命令行开发者工具」，点 安装，装完再启动一次。
    WINDOWS先到 python.org 下载安装，安装界面最下方务必勾选 Add python.exe to PATH。
  3. 双击启动

    进入解压后的 research-desk 文件夹：Mac 双击 启动研究台.command，Windows 双击 启动研究台.bat。浏览器会自动打开研究台。

    Mac 第一次如果提示「无法验证开发者」：右键点这个文件 → 打开。

  4. 别关那个命令窗口

    启动时会同时出现一个黑色或白色的命令窗口。用研究台期间别关它，关了研究台就退出了。窗口里写着研究台的地址，浏览器不小心关了，照着这个地址重新打开就行。

  5. 填 AI 接口

    点研究台右上角 设置，服务商选 DeepSeek，把 API Key 粘贴进去。还没有 Key 的话：

    打开 platform.deepseek.com → 手机号注册登录 → 充值几块钱 → 左侧 API keys → 创建 API key，复制那串以 sk- 开头的字符。

  6. 保存并测试

    模型名保持默认就行，直接点 保存并测试。看到「接口可用」就成功了，再点 保存。

    如果提示「模型名服务商不认识」，把「日常模型」改成 deepseek-chat 再测一次。

  7. 写一句你的研究方向（可选）

    在设置的「我的研究方向」写一句话，例如「钙钛矿太阳能电池的稳定性」。AI 讲解论文、排计划时会结合它。「论文分类」可以填几个分类，用逗号分开。

!
API Key 像一把私人钥匙只填进研究台的「设置」里。不要截图发群、不要发给别人，也不要写进笔记或上传到网上。
i
不填 API Key 也能用研究台整理论文、高亮和写笔记，只是翻译、讲解、问答这些 AI 功能暂时不能用。

认识七个页面

打开后看顶部这一排，点名字切换。迷路了就点「文库」。

📚
文库放论文、自动填论文信息、读 PDF、翻译、问答、高亮和笔记。大部分时间都在这里。
🗂️
组会专题把主讲论文、PPT 大纲、逐字稿和讨论记录放在一起。
📰
每日简报精读一篇论文，顺便看看你方向上的新论文。
💡
创新点池收集灵感，标记「待定 / 保留 / 放弃 / 已做」。
🧩
图解能点、能拖的讲解网页，把难懂的概念讲明白。
📈
进度看阅读时长、高亮、问答和新增论文。
📅
计划把阅读和研究任务排进一周里。
03

把论文放进文库

两种方法，任选一种。放进来以后，论文信息会自动填好。

最快

直接拖进来

  1. 进入 文库。
  2. 把电脑里的 PDF 拖到论文列表上，松手。
  3. 研究台会自动新建条目。
填信息

手动添加

  1. 点 + 添加论文。
  2. 填 arXiv 编号或标题，可以顺便选上 PDF。
  3. 点 保存到文库。
至少填 arXiv 编号、标题或 PDF 中的一项。

放进来以后

✨
论文信息会自动填好加进来几秒后，标题、作者、日期、出处（期刊或会议）、DOI 和摘要会自动查好（不用 API Key）。填了 API Key 的话，AI 还会读完论文，写好「核心贡献」「问题设定」「关联」，在「建议」里告诉你该精读还是略读，并从你的「论文分类」里选好方向。
它只填空着的格子，不会改你自己写的内容。以前加的论文，选中后在右侧「信息」页点 ✨ 自动填写 就能补上。
  1. 只差 PDF？
    选中论文，在右侧 附件 里上传。一次要导入很多 PDF，用列表上方的 导入本地 PDF 多选：新论文会自动建条目，已有条目会自动配上 PDF。
  2. 给它归类
    选中论文，在右侧 标签与分类 里选方向、加标签，以后好筛选。
i
用 Zotero 的同学在「设置」里填好 Zotero 数据文件夹（Mac 一般是 ~/Zotero），再点右上角 同步。不用 Zotero 的跳过这条。
04

读论文、划词翻译

研究台最常用的就是这一节。

  1. 打开 PDF
    双击论文那一行就进入阅读器；也可以选中论文，在右侧点 阅读与翻译。
  2. 调到舒服的样子
    顶部 − + 缩放，页码和左右箭头翻页；观看模式 有日常、护眼、暖色、夜间和黑白。
  3. 划一段，点翻译
    像选普通文字一样按住鼠标拖选，松开后弹出小菜单：翻译 看译文，解释 看通俗讲解，问 AI 结合整篇论文回答。
  4. 整页处理
    右侧 翻译 栏有 翻译本页 和 本页要点。翻过的页会保存，下次再看更快。
  5. 高亮和批注
    划词后点彩色圆点就是高亮；点 笔记 写下想法再 保存。以后点这段高亮，可以改颜色、补批注或删除。
  6. 回到文库
    点左上角 ← 返回文库。高亮、笔记、翻译和阅读时长都会自动保存，不用找保存按钮。
05

读完留下记录

✓ 标记读完

  1. 在阅读器上方或论文详情里点 标为已读，按钮会变成「✓ 已读完」。还没读完就先不点。

✎ 整理笔记

  1. 阅读器右侧 笔记 记方法要点、可改进的地方；文库右侧的「笔记」还能看到所有划下来的原文和批注。

？ 不懂就问

  1. 右侧 问答 可以直接点「讲了什么」「方法流程」「本页难点」「和我的方向」，也可以自己输入问题按回车。

→ 找下一篇

  1. 右侧 相关 能看到相似推荐、参考文献和后续引用，看中的点 加入文库。加进来的只是条目，PDF 需要另外添加。
i
拆解一整篇论文在阅读器里点 拆解论文 → 开始拆解，1–3 分钟后得到方法流程、关键概念、实验结果图和自测题。先看「费曼讲解」，再到「换你来讲」写下自己的复述，点 让 AI 检查我的讲解。
06

五个功能页：手动记录，或让 AI 帮你

每个页面都有两种用法：自己动手记，或者点带 ✨ 的按钮让 AI 生成。AI 生成的内容可以随时改、删。

组会专题

准备一次组会汇报

  1. 点 + 新建组会专题，填名称、日期，选主讲论文，点 创建。
  2. 点 ✨ AI 生成汇报准备，选汇报时长（10–30 分钟），点 开始生成。
  3. 专题里会出现摘要、可能被问的问题、准备待办，下方有「PPT 大纲」和「逐字稿」。
  4. 会后在「组会讨论记录」「会后结论」里记老师的意见。
生成的是大纲和文字稿，不会直接生成 .pptx 文件。
每日简报

精读一篇 + 新论文速览

  1. 点 ✨ AI 生成简报，选一篇要精读的论文。
  2. 想顺便看新论文，就勾选 arXiv，填英文关键词和时间范围。
  3. 点 开始生成，得到问题、方法、结论、3 条创新点和「今天能做的一小步」。
  4. 也可以点 ✍️ 手动写简报 自己记。
同一天再生成一次，会替换那天的简报，弹窗里会提示。
创新点池

把灵感留下来

  1. 点 + 手动添加 记下自己的想法；或点 ✨ AI 从论文提炼，选论文和条数。
  2. 给每条标「待定 / 保留 / 放弃 / 已做」，之后可以按状态筛选。
  3. 在想法下方补一句你的判断，方便以后回看。
AI 再生成想法时，会避开你标为「放弃」的方向。
图解

把难懂的东西讲明白

  1. 点 ✨ AI 生成图解，写清「想讲清楚什么」，可以选一篇论文结合着讲。
  2. 点 开始生成，1–3 分钟后得到一个能点、能拖的讲解网页。
  3. 手头有现成的讲解网页，用 + 导入 HTML 图解。
图解在隔离环境里运行，碰不到你的文库数据。
计划

安排这一周读什么

  1. 点 ✨ AI 帮我排计划，选开始日期、排几天、每天能用多少时间，写一句目标。
  2. AI 会用文库里还没读完的论文排出每天的任务。
  3. 也可以点 + 添加任务 自己加；做完了打勾。
进度

回顾这段时间做了什么

  1. 选 日 周 月 年，用箭头切换时间。
  2. 看阅读时长、读过的论文、高亮批注、问答和新增论文。
  3. 有阅读记录时，可以点 AI 帮我总结这段时间。
「读过的论文」只算读了半分钟以上、或有高亮、提问过的论文。
07

全文中英对照翻译（可选）

和划词翻译不一样：它保留论文原排版，另外生成一份中英对照的 PDF。需要先单独安装一次；只翻译一段文字的话不用装。

  1. 先退出研究台
    关掉研究台的网页和那个命令窗口。
  2. 双击安装
    在 research-desk 文件夹里：Mac 双击 安装全文翻译.command，Windows 双击 安装全文翻译.bat。等它显示「安装完成」，通常 5–15 分钟。
  3. 重新启动，打开一篇 PDF
    再双击启动研究台，在文库里双击打开论文。
  4. 点「全文翻译」
    阅读器上方点 全文翻译，等「翻译中」结束。第一次会再下载一些模型，多等几分钟。
  5. 看对照版
    完成后论文会多出 对照版，点开就是中英对照的 PDF。
i
不需要另外填 Key，但要联网全文翻译默认用一个免费的第三方翻译服务，所以不用填 DeepSeek Key；但需要联网，偶尔会慢或失败，过一会儿再试就好。翻译结果里的数字、公式和结论，请对照原文核实。
08

手机访问与备份

手机访问

在手机上看论文

  1. 只在电脑上用的话，什么都不用设置。
  2. 想用手机看：「设置」里勾选 允许同一 Wi-Fi / 手机热点里的手机打开研究台，设一个至少 6 位的访问密码，保存。
  3. 关掉命令窗口重新启动研究台，手机连同一个 Wi-Fi，打开设置里显示的地址，输入密码。
这个访问密码和 API Key 是两回事，不要设成一样的。
备份

论文和笔记不丢

  1. 你的一切都在 research-desk/data 文件夹里，备份就是把它复制一份。
  2. 研究台每天也会自动备份一次数据库，保留 14 天。
  3. 换新版本时，把旧版的 data 文件夹放进新版的 research-desk 里，论文和笔记就都带过去了。
09

遇到问题怎么办

点开问题看解决办法。

提示「还没有填写 API Key」或「API Key 不对」

回「设置」重新粘贴一次 Key，点 保存并测试。如果提示余额不足，到 DeepSeek 网站充值。

提示「模型名服务商不认识」

到「设置」把「日常模型」改成 deepseek-chat，深度模型改成 deepseek-reasoner 或留空，再点 保存并测试。用其他服务商时，模型名以它官网的列表为准。

浏览器关了，想继续用

命令窗口还开着的话，打开窗口里显示的地址（通常是 http://127.0.0.1:8765；如果这个端口被占用，研究台会自动换成 8766、8767……以窗口里写的为准）。窗口也关了的话，重新双击启动文件。

Mac 双击启动文件，提示「没有权限」或「无法打开」

先试 右键 点启动文件 → 打开。还不行：打开「终端」（在启动台里搜「终端」），输入 chmod +x （末尾有个空格），把 启动研究台.command 拖进终端窗口，按回车，再双击它。

Windows 双击后提示没有 Python

到 python.org 安装 Python，安装时勾选 Add python.exe to PATH，装好后再双击启动文件。

点「全文翻译」提示还没安装

这是功能还没装，不是论文坏了。退出研究台，双击 安装全文翻译，装完重新打开。只想翻译一段的话不用装，直接划词点「翻译」。

论文信息没有自动填上

基本信息来自 arXiv 和 Semantic Scholar：有 arXiv 编号、DOI，或者 PDF 第一页印着编号的论文最容易查到；只在 arXiv 上的预印本，「出处」常常是空的，这是正常的。核心贡献、问题设定这些要填了 API Key 才会写。可以选中论文，在「信息」页点 ✨ 自动填写 再试一次，或者自己补上。

「相关」一直在转

第一次查询要等几秒到十几秒，之后一周内再打开同一篇是秒出。「本文引用的经典」是空的，一般是数据源没有公开这篇的参考文献，界面上会说明，直接看论文最后的参考文献就行。

「拆解论文」说读不出文字

扫描版或图片版的 PDF 里没有文字，AI 读不到。换一个能选中文字的版本（比如 arXiv 上下载的）再试。

AI 说的和原文不一样

以论文原文为准。用页码回到原文核对，尤其是数字、公式和结论。

✓
日常使用只需要关心两件事：研究台的页面能不能打开，AI 能不能正常回答。其他技术细节都不用管。
本手册随研究台开源包一起发布，按钮名以当前开源版界面为准。请勿把 API Key 写进本文件或上传到公开仓库。
