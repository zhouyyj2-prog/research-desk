# 进阶：自动每日简报

> 这是可选功能，不用也完全不影响使用。

在研究台的「每日简报」页点「AI 生成简报」就能随时生成一份。如果想**每天早上自动**生成，可以配一个「自动找论文的助手」，每天把简报送进研究台，做法如下。

研究台不会在后台定时运行，自动生成这件事交给任何能定时运行、能写本地文件的 AI 工具（例如 Claude 的定时任务，或你自己写的脚本），让它每天把结果写成一个 JSON 文件，放进 `research-desk/data/inbox/`。研究台启动或点「同步」时会自动导入。

## 最简单的做法

把下面这段话交给你的定时任务（把尖括号里的内容换成你自己的）：

> 每天早上帮我准备一份论文简报。我的研究方向是 <你的方向>。
> 1. 先读 `<研究台所在位置>/research-desk/data/snapshot.json`，里面是我已有的论文和想法，不要重复推荐。
> 2. 检索最近两周的新论文，选 4–6 篇略读、1 篇精读。只选真实存在、能打开的论文，链接必须来自检索结果。
> 3. 精读那篇写清问题、方法、结果、局限，再提出 3–5 条可以改进的想法。
> 4. 按 [示例文件](examples/brief-example.json) 的格式写成 JSON，保存为 `<研究台所在位置>/research-desk/data/inbox/<今天日期>-brief.json`。公式用 `$...$` 写成 LaTeX。

## 文件格式

照着 [`examples/brief-example.json`](examples/brief-example.json) 改即可。要点：

- 文件里有三类内容：`papers`（论文）、`ideas`（创新点）、`briefs`（当天简报），每条都必须有 `id`。论文的 `id` 建议用 arXiv 编号或 DOI。
- `mode` 写 `create`：已经有的 `id` 会跳过，不会覆盖。
- 想修改已有条目（比如把某个想法标为「保留」），用 `updates`：`[{"col": "ideas", "id": "…", "patch": {"status": "保留"}}]`。
- `direction` 写你在「设置 → 论文分类」里填的分类名；写了新名字也会自动出现在左侧。
- 导入后文件会移到 `data/inbox/done/`。
